# Portfólio Pessoal — Lucas de Oliveira Coelho

Portfólio online desenvolvido para a **Atividade Prática da disciplina Fundamentos da Programação Web** da UNINTER (curso de Ciência da Computação).

## 🌐 Site publicado

https://lucasolicoe.github.io/portfolio-lucas-coelho/

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3** puro (sem Bootstrap, Tailwind ou qualquer framework)
- **JavaScript** puro (sem React, Vue, jQuery ou qualquer biblioteca)

## 📑 Estrutura

Single Page Application com navegação por âncoras e quatro seções:

1. **Sobre mim** — apresentação, hobbies e interesses
2. **Formação** — trajetória acadêmica, cursos e idiomas
3. **Portfólio** — projetos com filtros por categoria
4. **Contato** — formulário com validação e simulação de envio

## ✨ Funcionalidades JavaScript

- Validação completa do formulário (nome, e-mail e mensagem)
- Simulação do envio com modal de confirmação
- Tema claro/escuro com detecção da preferência do sistema
- Menu hamburger responsivo
- Filtros do portfólio (mostrar/esconder por categoria)
- Destaque automático do link ativo conforme a rolagem

## 📁 Estrutura de arquivos

```
portfolio-lucas-coelho/
├── index.html      Estrutura e conteúdo
├── estilo.css      Estilos (variáveis, tema, layout, componentes)
├── script.js       Interatividade e validações
└── README.md       Este arquivo
```

## 🚀 Como executar localmente

Basta abrir o arquivo `index.html` no navegador.
